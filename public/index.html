Running Locally or Deploying on Render

1. Running Locally on Your Laptop (Windows)

You can run this server on your laptop anytime without installing extra tools:

  1. Double-click start.bat in this project folder.
  2. It will automatically start the server and open http://localhost:3000 in your browser!
  3. To stop the server, simply close the command prompt window.
.\start.bat

2. Deploying on Render (Free Cloud Hosting)

Deploy this app to the cloud so anyone can access it via a web link:

  1. Push this project folder to your GitHub repository:
    git init
    git add .
    git commit -m "GST Invoice Aggregator"
    git remote add origin YOUR_REPO_URL
    git push -u origin main
  2. Go to Render.com and sign in.
  3. Click New + → Web Service → Connect your GitHub repository.
  4. Render automatically detects settings from render.yaml or enter:
    • Runtime: Node
    • Build Command: npm install
    • Start Command: npm start
  5. Click Deploy Web Service. In ~1 minute, your cloud URL will be live!
